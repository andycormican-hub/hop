# Hop

Hop parks idle on-chain cash into yielding tokenized assets and pulls it back for payments. It refuses the hop when settlement cannot complete.

Demo only. Does not move client funds. Not an offer of securities.

## Open the demo
Download `HOP.html` and open it in a browser.

## Screens
- Policy: spendable floor, yield sleeve, pull-back time
- Preview: park or recall, YES/NO settle-now, Blocked vs Queue
- Ledger: Queued / Settled / Blocked / Refused
